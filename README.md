# Проект "Интеренет-магазина"
## Описание:
SkyStore — это интернет-магазин цифровых товаров на Django. 
Проект позволяет просматривать каталог товаров,
оставлять заявки через форму обратной связи и управлять контентом 
через административную панель.

Проект создан в рамках обучения Django 
и демонстрирует базовую настройку веб-приложения с использованием шаблонов, 
маршрутизации и обработки форм.
## Установка:
+ Установите на свой компьютер GitHub.
+ Клонируйте репозиторий с GitHub  с помощью веб-URL.
```
 git clone 
Примените миграции базы данных:
bash
python manage.py migrate
Запустите сервер разработки:
bash
python manage.py runserver
```
## Использование:
Использование:
1. Просмотр каталога товаров
Главная страница отображает список товаров с названием, ценой и кратким описанием. Карточки товаров стилизованы с использованием Bootstrap.

2. Форма обратной связи
На странице контактов реализована форма для отправки сообщений:

Поля: Имя, Телефон, Сообщение

После отправки появляется уведомление об успехе или ошибке

Данные выводятся в консоль сервера (для демонстрации)
+ Основные функции:
Контроллеры (Views):
home() — отображение главной страницы с каталогом товаров.

contacts() — обработка формы обратной связи:

При GET-запросе отображает страницу с формой

При POST-запросе обрабатывает данные и выводит уведомление
