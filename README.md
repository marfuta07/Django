# Проект "Интеренет-магазина"
## Описание:
SkyStore — это интернет-магазин цифровых товаров на Django. 
Проект позволяет просматривать каталог товаров,
оставлять заявки через форму обратной связи и управлять контентом 
через административную панель.

Проект создан в рамках обучения Django 
и демонстрирует базовую настройку веб-приложения с использованием шаблонов, 
маршрутизации и обработки форм.
## Установка:
+ Установите на свой компьютер GitHub.
+ Клонируйте репозиторий с GitHub  с помощью веб-URL.
```
 git clone 
Примените миграции базы данных:
bash
python manage.py migrate
Запустите сервер разработки:
bash
python manage.py runserver
```
## Основные возможности

- 🏠 Главная страница с каталогом товаров
- 📞 Страница контактов с формой обратной связи
- 🎨 Адаптивный дизайн на Bootstrap 5
- 📝 Валидация формы обратной связи
- 🗄️ Подключение PostgreSQL
- 📦 Модели `Product` и `Category` с полной настройкой
- 🖥️ Административная панель для управления товарами
- 📊 Фикстуры для загрузки тестовых данных
- ⚙️ Кастомная команда `load_test_data`

🖥️ Административная панель
Доступна по адресу: http://127.0.0.1:8000/admin/

Настройки админки:

Категории: отображаются поля id и name

Товары: отображаются поля id, name, price, category

Фильтрация: по категории

Поиск: по полям name и description
